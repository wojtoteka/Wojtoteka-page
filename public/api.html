🚀 Szybki start

Aby rozpocząć korzystanie z API formularza kontaktowego, potrzebujesz jedynie klucza API. Klucz otrzymujesz od administratora serwisu po założeniu konta.

Jak to działa?

  1. Administrator tworzy dla Ciebie klucz API i konto w panelu
  2. Dane logowania (email + hasło) otrzymujesz mailem
  3. Wklejasz formularz na swoją stronę z kluczem API
  4. Wiadomości trafiają do Twojego panelu: wojtoteka.ovh/panel
  5. Opcjonalnie — dostajesz powiadomienia email o nowych wiadomościach
💡 Nie masz jeszcze klucza API? Skontaktuj się z administratorem przez wojtoteka.ovh/kontakt.html

📍 Endpoint

Wszystkie wiadomości wysyłaj na jeden endpoint:

POST https://wojtoteka.ovh/api/v1/contact

CORS preflight:

OPTIONS https://wojtoteka.ovh/api/v1/contact
⚠️ Endpoint akceptuje wyłącznie żądania POST z nagłówkiem Content-Type: application/json

🔑 Autoryzacja

Każde żądanie musi zawierać nagłówek X-API-Key z Twoim kluczem API.

X-API-Key: twoj-klucz-api-tutaj

Przykład nagłówków

{
  "Content-Type": "application/json",
  "X-API-Key": "abc123def456ghi789..."
}
⚠️ Nigdy nie udostępniaj klucza API publicznie w repozytoriach. Klucz jest widoczny w kodzie HTML strony — to normalne dla formularzy kontaktowych, ale nie używaj go do wrażliwych operacji.

📋 Pola formularza

Dostępne pola zależą od konfiguracji klucza API. Administrator decyduje, które pola są zbierane. Jeśli pole jest włączone dla Twojego klucza — jest wymagane w żądaniu.

Pole Typ Opis Walidacja
name string Imię / Nick nadawcy 1–255 znaków
email string Adres email nadawcy Poprawny format email
phone string Numer telefonu 1–50 znaków
subject string Tytuł / Temat wiadomości 1–255 znaków
message string Treść wiadomości 1–5000 znaków
💡 Przykład: Jeśli administrator włączył pola: name email message — to wysyłasz w body JSON dokładnie te 3 pola. Pola phone i subject będą ignorowane.

Przykładowe body (JSON)

{
  "name": "Jan Kowalski",
  "email": "jan@example.com",
  "phone": "+48 123 456 789",
  "subject": "Pytanie o współpracę",
  "message": "Cześć! Chciałbym zapytać o..."
}

📊 Kody odpowiedzi

Kod Opis Przykład odpowiedzi
200 Wiadomość wysłana pomyślnie {"message": "Wiadomość została wysłana pomyślnie"}
400 Brak wymaganego pola lub nieprawidłowe dane {"message": "Pole 'email' jest wymagane..."}
401 Brak lub nieprawidłowy klucz API {"message": "Nieprawidłowy klucz API"}
403 Twoje IP zostało zbanowane {"message": "Twoje IP zostało zablokowane"}
429 Zbyt wiele żądań (rate limit: 30/h) {"message": "Zbyt wiele wiadomości..."}
500 Wewnętrzny błąd serwera {"message": "Wewnętrzny błąd serwera"}

💻 Przykłady integracji

HTML + JavaScript (zalecane)

Najprostszy sposób — wklej na swoją stronę HTML:

<!-- Formularz kontaktowy — Wojtoteka API -->
<form id="contactForm">
    <input type="text" name="name" placeholder="Imię" required>
    <input type="email" name="email" placeholder="Email" required>
    <input type="text" name="subject" placeholder="Temat" required>
    <textarea name="message" placeholder="Wiadomość..." required></textarea>
    <button type="submit">Wyślij</button>
</form>

<div id="formStatus"></div>

<script>
document.getElementById('contactForm').addEventListener('submit', async (e) => {
    e.preventDefault();
    const form = e.target;
    const btn = form.querySelector('button[type="submit"]');
    const status = document.getElementById('formStatus');

    btn.disabled = true;
    btn.textContent = 'Wysyłanie...';

    try {
        const response = await fetch('https://wojtoteka.ovh/api/v1/contact', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
                'X-API-Key': 'TWOJ_KLUCZ_API'
            },
            body: JSON.stringify({
                name: form.name.value,
                email: form.email.value,
                subject: form.subject.value,
                message: form.message.value
            })
        });

        const data = await response.json();

        if (response.ok) {
            status.innerHTML = '<p style="color:green">✅ ' + data.message + '</p>';
            form.reset();
        } else {
            status.innerHTML = '<p style="color:red">❌ ' + data.message + '</p>';
        }
    } catch (err) {
        status.innerHTML = '<p style="color:red">❌ Błąd połączenia</p>';
    } finally {
        btn.disabled = false;
        btn.textContent = 'Wyślij';
    }
});
</script>

?>

🌐 CORS

API wspiera CORS (Cross-Origin Resource Sharing), dzięki czemu możesz wysyłać żądania z dowolnej domeny bezpośrednio z przeglądarki.

Nagłówki CORS w odpowiedzi

Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: POST, OPTIONS
Access-Control-Allow-Headers: Content-Type, X-API-Key
✅ Nie musisz konfigurować nic po swojej stronie. Żądania z fetch() i XMLHttpRequest działają od razu z każdej domeny.

⚡ Rate Limiting

Aby zapobiec spamowi, API ma limity żądań:

Limit Wartość Opis
API kontakt 30 żądań / godzinę Na adres IP
Rozmiar body max ~50 KB Limit parsera JSON
Pole message max 5000 znaków Treść wiadomości

Przy przekroczeniu limitu otrzymasz odpowiedź 429 z nagłówkiem Retry-After.

⚠️ Jeśli Twoje IP zostanie zbanowane (np. za spam), otrzymasz 403. Kontaktuj się z właścicielem klucza API.

🧪 Przetestuj API

Wpisz swój klucz API, wczytaj konfigurację i przetestuj endpoint na żywo. Dzięki temu tester dopasuje się do Twojego klucza.

💡 Po zmianie konfiguracji klucza API kliknij ponownie „Wczytaj konfigurację”, aby odświeżyć formularz testowy.

❓ FAQ

Jak uzyskać klucz API?

Skontaktuj się z administratorem serwisu przez formularz na wojtoteka.ovh/kontakt.html. Administrator utworzy klucz, konto w panelu i wyśle dane na Twój email.

Skąd wiem, jakie pola są włączone dla mojego klucza?

Informację tę znajdziesz w panelu administracyjnym przy swoim kluczu API, lub zapytaj administratora. Jeśli wyślesz pole, które nie jest włączone — zostanie ono zignorowane.

Czy mogę używać API z wielu domen?

Tak! CORS pozwala na żądania z dowolnego originu. Jeden klucz API może obsługiwać wiele stron.

Co się stanie, gdy ktoś nadużywa mojego formularza?

Możesz zbanować IP nadawcy z poziomu panelu. Ban jest per-klucz API. Dodatkowo automatyczny rate limiting (30/h) ogranicza spam.

Czy wiadomości gdzieś się przechowują?

Tak, wszystkie wiadomości są zapisywane w bazie danych i widoczne w panelu. Możesz je przeglądać i usuwać.

Czy dostanę email przy nowej wiadomości?

Jeśli administrator ustawił email powiadomień dla Twojego klucza API — tak, dostaniesz email za każdym razem, gdy ktoś wyśle wiadomość przez Twój formularz.

Zapomniałem hasła do panelu

Na stronie logowania panelu kliknij „Nie pamiętam hasła”. Na Twój e-mail zostanie wysłany 6-cyfrowy kod, za pomocą którego ustawisz nowe hasło.

Moje konto zostało zablokowane

Po 5 nieudanych próbach logowania konto jest blokowane na 15 minut. Poczekaj lub skontaktuj się z administratorem, który może odblokować konto ręcznie.
